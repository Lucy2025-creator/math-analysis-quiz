# 数分刷题

华东师范大学《数学分析》第六版（上册）**第 1–4 章课后习题**在线刷题页。

在线访问：<https://lucy2025-creator.github.io/math-analysis-quiz/>

纯静态站点，无后端、无构建步骤，所有学习记录保存在浏览器 `localStorage`。

## 功能

- **题库**：第 1–4 章共 198 道课后习题，按章节 / 小节 / 题型 / 关键词浏览与搜索。
- **选题**：随机抽题（自由设定数量）、全部题目、只练错题、只练未做、只练收藏、自定义勾选；支持打乱顺序或按原顺序。
- **展示**：整卷模式一次看完，或单题模式逐题推进；答题过程中可随时切换。
- **解析**：每题配有答案与分步解析，公式用 KaTeX 渲染；证明题按小问给出关键推理。
- **自评**：对照解析标记“做对了 / 做错了”，错题自动进入错题本。
- **错题本**：集中重练、手动移出、按最近错误时间排序。
- **收藏与笔记**：收藏想二刷的题；每题可写笔记 / 草稿，自动保存。
- **统计**：章节覆盖度、累计正确率、最近 14 天练习量、最近练习记录、连续学习天数。
- **其他**：深色 / 浅色主题、题目字号、答题卡、计时、快捷键、打印试卷、备份导出 / 导入、离线缓存（PWA）。

## 本地运行

站点使用相对路径，直接双击 `index.html` 也能打开；若要测试 Service Worker / 离线缓存，请起一个本地服务器：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 部署到 GitHub Pages

仓库已按 GitHub Pages 的“从分支部署”方式组织：

1. 将本目录推到 GitHub 仓库的 `main` 分支；
2. 仓库 **Settings → Pages → Build and deployment**，Source 选 **Deploy from a branch**，Branch 选 `main` / `(root)`；
3. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`。

`.nojekyll` 已加入，避免 Jekyll 处理静态资源。

## 数据说明

- 题目文字依据教材 OCR 整理，并对明显的公式 / 符号错误做了校订；个别图形题（1.3 第 3 题）从教材截图裁剪配图。
- 解析为学习参考，由 AI 辅助整理并经人工抽样核对。证明题建议先独立完成，再对照解析检查关键步骤。
- 教材、题目与插图的版权归原作者及高等教育出版社所有；本站仅用于个人学习，请勿用于商业分发。

## 快捷键（单题模式）

- `←` / `→`：上一题 / 下一题
- `空格`：展开 / 收起解析
- `1`：做对了
- `2`：做错了
