# 数分刷题

华东师范大学《数学分析》第六版（上册）**第 1–6 章课后习题**在线刷题页，并附**第 5–6 章课本知识点**速查。

在线访问：<https://lucy2025-creator.github.io/math-analysis-quiz/>

纯静态站点，无构建步骤；文字记录优先保存在浏览器 `localStorage`，作答图片保存在 `IndexedDB`。登录后通过 Supabase 做账号与云同步（可选，未配置时一切照旧本地使用）。

## 功能

- **题库**：第 1–6 章共 331 道课后习题，按章节 / 小节 / 题型 / 关键词浏览与搜索。
- **课本知识点**：新增第 5 章“导数与微分”、第 6 章“微分中值定理及其应用”的定义、定理、公式、证明步骤与易混注记；按章节 / 小节浏览，支持全库搜索，定理证明可折叠展开，公式用 KaTeX 渲染。
- **题型聚类**：23 个题型，覆盖全部 198 题；每个题型有“知识点总结 + 答题模板 + 代表题”，解析里可展开查看。
- **选题**：随机抽题（自由设定数量）、全部题目、只练错题、只练未做、只练收藏、只练标记、自定义勾选、按题型比例；支持打乱、原顺序或“久未练优先”。
- **高级筛选**：按难度（1–3）、题目复杂度（小题/中题/大题，按题干+解析篇幅估算）、练过时间（从未/7 天内/8–30 天/30 天以上）、知识点关键词（支持输入联想与多选，命中任一即可）筛选。
- **题型配比**：证明、计算、讨论、辨析、作图、解答可分别设置百分比，例如“计算 40%、证明 40%”，按总数自动分配并归一化。
- **教材引用**：题目出现“定理 3.1”“第 4 题结论”等引用时，题干下方直接贴出教材定理原文或所引题的结论；引用的题号可点击跳转。
- **展示**：整卷模式一次看完，或单题模式逐题推进；答题过程中可随时切换。
- **放大题目**：单题/详情页可打开大字号阅读弹窗。
- **换一题**：单题练习中可随机替换当前题，不打断整场练习。
- **标记**：给任意题打上“重点”标记，题库可按标记筛选、集中练。
- **解析**：每题配有答案与分步解析，公式用 KaTeX 渲染；证明题按小问给出关键推理；解析尽量只使用当前章及之前的知识。
- **自评**：对照解析标记“做对了 / 做错了”，错题自动进入错题本。
- **错题本**：集中重练、手动移出、按最近错误时间排序。
- **收藏与笔记**：收藏想二刷的题；每题可写文字痕迹 / 笔记，自动保存。
- **作答痕迹**：每题可上传多张答题纸、草稿或订正照片；图片压缩后保存在本机 IndexedDB，可点开大图、删除。
- **错题复习文档**：按“最近 7/30/90 天 / 全部 + 章节”导出近期错题，自动带上题型总结、答题模板 / 关键步骤、本题思路、答案、教材引用，以及自己的文字痕迹和图片；生成单个手机友好的 HTML，公式为 MathML、图片内嵌，可离线打开或打印成 PDF。
- **账号与云同步**：Supabase 邮箱注册 / 登录 / 找回密码；进度、错题、笔记与作答图片跨设备同步。联网时保存后自动推送并用 Realtime 接收其他设备改动；断网时只写本地，恢复网络后自动补传。支持“用云端覆盖本机 / 用本机覆盖云端”。
- **艾宾浩斯复习**：首次作答后自动排入 7 次复习（1、2、4、7、15、30、60 天）；答对到期题推进，答错回到第 0 次；首页 / 统计页有“今日复习”入口。
- **每日打卡**：作答即打卡，统计页有最近 30 天打卡日历与连续打卡天数。
- **统计**：章节覆盖度、累计正确率、最近 14 天练习量、最近练习记录、7 次复习进度。
- **其他**：深色 / 浅色主题、题目字号、答题卡、计时、快捷键、打印试卷、备份导出 / 导入、离线缓存（PWA）。JSON 备份含文字与进度；作答图片随错题复习文档一起导出。

## 本地运行

站点使用相对路径，直接双击 `index.html` 也能打开；若要测试 Service Worker / 离线缓存，请起一个本地服务器：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 部署到 GitHub Pages

仓库已按 GitHub Pages 的“从分支部署”方式组织：

1. 将本目录推到 GitHub 仓库的 `main` 分支；
2. 仓库 **Settings → Pages → Build and deployment**，Source 选 **Deploy from a branch**，Branch 选 `main` / `(root)`；
3. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`。

`.nojekyll` 已加入，避免 Jekyll 处理静态资源。

## 配置云同步（可选）

1. 新建 Supabase 项目；
2. 在 SQL Editor 运行 [`supabase/schema.sql`](supabase/schema.sql)；
3. 在 Authentication → URL Configuration 填线上地址；
4. 打开站点 `#/account`，或在 `assets/js/supabase-config.js` 填 Project URL 与 anon public key。

完整步骤见 [`supabase/README.md`](supabase/README.md)。只使用 anon key，不要把 service_role key 放进前端。

## 数据说明

- 题目文字依据教材 OCR 整理，并对明显的公式 / 符号错误做了校订；个别图形题（1.3 第 3 题）从教材截图裁剪配图。
- 解析为学习参考，由 AI 辅助整理并经人工抽样核对；第 1–3 章解析已检查并移除“连续、导数、积分、洛必达、泰勒”等后续章节方法。证明题建议先独立完成，再对照解析检查关键步骤。
- 复习间隔按 1、2、4、7、15、30、60 天安排，共 7 次；这是简化版艾宾浩斯安排，可按自己的节奏使用。
- 教材、题目与插图的版权归原作者及高等教育出版社所有；本站仅用于个人学习，请勿用于商业分发。
